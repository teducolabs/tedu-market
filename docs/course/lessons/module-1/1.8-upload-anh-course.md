## **Nội dung chính**

### **1. Object Storage & Presigned URL — vì sao không proxy qua backend**

Từ bài 1.1 đến 1.7, Course Aggregate đã có đủ Title, Pricing, danh sách Lesson — nhưng chưa có ảnh đại diện (thumbnail). Đây là bài đầu tiên trong khóa xử lý file nhị phân (binary), và cách xử lý sẽ khác hẳn phần còn lại: ảnh không đi qua Command/Query như dữ liệu quan hệ, mà đi thẳng vào object storage — cụ thể ở đây là MinIO, chạy local qua Docker Compose, tương thích 100% với S3 API của AWS.

Có 2 cách kiến trúc để client upload ảnh lên server, và outline khóa học đã chốt dùng cách thứ 2:

- Cách 1 — Proxy qua backend: client gửi file (multipart/form-data, IFormFile) lên API, API nhận toàn bộ byte rồi ghi lên storage. Backend trở thành điểm nghẽn băng thông — ảnh 5MB đi qua backend 2 lần (client → API → storage) thay vì 1 lần.
- Cách 2 — Presigned URL (đã chọn): API chỉ sinh ra 1 URL có chữ ký (signature) hợp lệ trong thời gian ngắn. Client dùng URL đó PUT thẳng file lên MinIO — backend không chạm vào 1 byte ảnh nào.

Cơ chế presigned URL hoạt động dựa trên chữ ký HMAC ký sẵn các tham số (bucket, object key, thời điểm hết hạn) bằng secret key của server — client không bao giờ thấy secret key, chỉ thấy URL đã ký. MinIO/S3 xác thực chữ ký này khi nhận PUT request, không cần biết gì về user hay JWT của hệ thống TEDU Market.

> **📘 Ghi chú giảng viên:** *Học viên hay hỏi: "Vậy ai cũng có URL này thì upload được à?" — Đúng, nhưng URL chỉ sống trong khoảng ngắn (ở bài này đặt 5 phút) và object key được sinh ngẫu nhiên bằng Guid nên không đoán được. Đánh đổi thật sự nằm ở chỗ khác: backend không kiểm tra được dung lượng hay định dạng file TRƯỚC khi nó lên MinIO, vì backend không đứng giữa luồng upload. Đây là lý do phải validate đuôi file khi sinh presigned URL (ResolveContentType bên dưới) — kiểm soát bằng cách giới hạn nội dung được PHÉP upload lên, không phải bằng cách kiểm tra nội dung ĐÃ upload.*

Sơ đồ luồng đầy đủ của bài này — ghi nhớ vì Module 6.5 (React Admin) sẽ implement lại đúng luồng này ở phía UI:

- Bước 1 — Admin UI gọi POST /api/v1/courses/{id}/thumbnail/upload-url → nhận về { objectKey, uploadUrl, expiresAt }.
- Bước 2 — Admin UI PUT file ảnh thẳng lên uploadUrl (gọi trực tiếp đến MinIO, không qua domain của TEDU Market API).
- Bước 3 — Admin UI gọi PUT /api/v1/courses/{id}/thumbnail với objectKey vừa upload thành công → Course Aggregate lưu lại objectKey này.

Nói cách khác: bài này viết 2 Command, không phải 1. Deliverable của outline ghi "Command UpdateCourseThumbnail" cho bước xác nhận (bước 3) — bước sinh URL (bước 1) cũng là một Command vì nó có side-effect thật (đảm bảo bucket tồn tại, sinh object key), dù không ghi gì xuống Postgres.

### **2. Domain: thêm Thumbnail vào Course Aggregate**

Nhắc lại nguyên tắc đã học ở bài 1.3: mọi thay đổi lên Course phải đi qua chính Aggregate Root, không update thẳng property. Thumbnail cũng vậy — thêm 1 method SetThumbnail(...) vào Course thay vì để property có public setter.

*backend/src/TeduMarket.Domain/Courses/Course.cs (bổ sung)*

```csharp
namespace TeduMarket.Domain.Courses;
 
public sealed class Course
{
    // ... Id, Title, Description, CategoryId, InstructorId, Pricing, Lessons — đã có từ bài 1.1–1.4
 
    public string? ThumbnailObjectKey { get; private set; }
 
    public void SetThumbnail(string objectKey)
    {
        if (string.IsNullOrWhiteSpace(objectKey))
            throw new ArgumentException(
                "Object key ảnh thumbnail không được để trống.", nameof(objectKey));
 
        ThumbnailObjectKey = objectKey;
    }
}
```

Lưu ý: Course chỉ lưu ObjectKey (đường dẫn tương đối trong bucket, ví dụ courses/{id}/thumbnail/xxxx.png), không lưu full URL. Lý do: base URL của MinIO/CDN có thể đổi giữa dev, staging, production (Module 9 sẽ đưa MinIO ra sau CDN) — nếu lưu full URL, đổi domain là phải migrate dữ liệu. Việc ghép ObjectKey thành URL hiển thị được làm ở tầng Application/Api lúc trả response, không phải trách nhiệm của Domain.

*CreateCourseThumbnailUploadUrlCommandValidator.cs*

```csharp
public sealed class CreateCourseThumbnailUploadUrlCommandValidator
    : AbstractValidator<CreateCourseThumbnailUploadUrlCommand>
{
    private static readonly string[] AllowedExtensions = [".jpg", ".jpeg", ".png", ".webp"];
 
    public CreateCourseThumbnailUploadUrlCommandValidator()
    {
        RuleFor(x => x.CourseId).NotEmpty();
 
        RuleFor(x => x.FileExtension)
            .NotEmpty()
            .Must(ext => AllowedExtensions.Contains(ext.ToLowerInvariant()))
            .WithMessage($"Chỉ chấp nhận định dạng: {string.Join(", ", AllowedExtensions)}");
    }
}
```

*CreateCourseThumbnailUploadUrlCommandHandler.cs*

```csharp
public sealed class CreateCourseThumbnailUploadUrlCommandHandler(
    ICourseRepository courseRepository,
    IFileStorageService fileStorageService)
    : IRequestHandler<CreateCourseThumbnailUploadUrlCommand, PresignedUploadResult>
{
    private static readonly TimeSpan UploadUrlExpiry = TimeSpan.FromMinutes(5);
 
    public async Task<PresignedUploadResult> Handle(
        CreateCourseThumbnailUploadUrlCommand request,
        CancellationToken cancellationToken)
    {
        var course = await courseRepository.GetByIdAsync(request.CourseId, cancellationToken)
            ?? throw new CourseNotFoundException(request.CourseId);
 
        // Guid trong object key để tránh cache ảnh cũ khi đổi thumbnail nhiều lần
        var objectKey = $"courses/{course.Id}/thumbnail/{Guid.NewGuid():N}{request.FileExtension}";
        var contentType = ResolveContentType(request.FileExtension);
 
        return await fileStorageService.CreatePresignedUploadUrlAsync(
            objectKey, contentType, UploadUrlExpiry, cancellationToken);
    }
 
    private static string ResolveContentType(string extension) => extension.ToLowerInvariant() switch
    {
        ".jpg" or ".jpeg" => "image/jpeg",
        ".png" => "image/png",
        ".webp" => "image/webp",
        _ => throw new NotSupportedException($"Định dạng ảnh '{extension}' chưa được hỗ trợ.")
    };
}
```

> **📘 Ghi chú giảng viên:** *Handler dùng primary constructor (cú pháp có từ C# 12, không phải riêng C# 14) — đây là cách viết chuẩn cho mọi Handler từ .NET 8 trở đi, học viên đã thấy quen mắt từ bài 0.4. Điểm mới thật sự ở bài này là bước gọi courseRepository trước rồi mới sinh objectKey — bắt buộc kiểm tra Course tồn tại trước khi cấp quyền upload, tránh việc học viên đoán được CourseId rồi xin presigned URL cho course không tồn tại hoặc không thuộc quyền của mình (Authorization đầy đủ dành cho Module 3, ở đây chỉ chặn ở mức tồn tại).*

*backend/src/TeduMarket.Infrastructure/Storage/MinioFileStorageService.cs*

```csharp
using Minio;
using Minio.DataModel.Args;
 
namespace TeduMarket.Infrastructure.Storage;
 
internal sealed class MinioFileStorageService(
    IMinioClient minioClient,
    IOptions<MinioOptions> options) : IFileStorageService
{
    private readonly MinioOptions _options = options.Value;
 
    public async Task<PresignedUploadResult> CreatePresignedUploadUrlAsync(
        string objectKey,
        string contentType,
        TimeSpan expiry,
        CancellationToken cancellationToken)
    {
        await EnsureBucketExistsAsync(cancellationToken);
 
        var args = new PresignedPutObjectArgs()
            .WithBucket(_options.Bucket)
            .WithObject(objectKey)
            .WithExpiry((int)expiry.TotalSeconds);
 
        var uploadUrl = await minioClient.PresignedPutObjectAsync(args);
 
        return new PresignedUploadResult(objectKey, uploadUrl, DateTimeOffset.UtcNow.Add(expiry));
    }
 
    private async Task EnsureBucketExistsAsync(CancellationToken cancellationToken)
    {
        var existsArgs = new BucketExistsArgs().WithBucket(_options.Bucket);
        var exists = await minioClient.BucketExistsAsync(existsArgs, cancellationToken);
 
        if (!exists)
        {
            var makeBucketArgs = new MakeBucketArgs().WithBucket(_options.Bucket);
            await minioClient.MakeBucketAsync(makeBucketArgs, cancellationToken);
        }
    }
}
```

Đăng ký IMinioClient và IFileStorageService trong DependencyInjection.cs của Infrastructure — cùng chỗ đã đăng ký DbContext (bài 0.6) và Dapper connection factory (bài 0.8):

*backend/src/TeduMarket.Infrastructure/DependencyInjection.cs (bổ sung)*

```csharp
public static IServiceCollection AddInfrastructure(
    this IServiceCollection services, IConfiguration configuration)
{
    // ... đăng ký EF Core DbContext, Dapper, OpenIddict — đã có từ các bài trước
 
    services.Configure<MinioOptions>(configuration.GetSection(MinioOptions.SectionName));
 
    var minioOptions = configuration.GetSection(MinioOptions.SectionName).Get<MinioOptions>()
        ?? throw new InvalidOperationException("Thiếu cấu hình MinIO trong appsettings.");
 
    services
        .AddMinio(minioOptions.Endpoint)
        .WithStaticCredentials(minioOptions.AccessKey, minioOptions.SecretKey);
 
    services.AddScoped<IFileStorageService, MinioFileStorageService>();
 
    return services;
}
```

### **5. UpdateCourseThumbnailCommand & Endpoint — nối luồng end-to-end**

Đây chính là Command mà outline gọi tên ở mục Deliverable. Nhận objectKey (đã upload thành công ở bước 2 của sơ đồ) và ghi vào Course Aggregate qua SetThumbnail.

*UpdateCourseThumbnailCommandHandler.cs*

public sealed class UpdateCourseThumbnailCommandHandler(ICourseRepository courseRepository)
    : IRequestHandler<UpdateCourseThumbnailCommand>

public sealed record CreateThumbnailUploadUrlRequest(string FileExtension);

group.MapPost("/{id:guid}/thumbnail/upload-url", async (
    Guid id,
    CreateThumbnailUploadUrlRequest request,
    ISender sender,
    CancellationToken cancellationToken) =>
{
    var command = new CreateCourseThumbnailUploadUrlCommand(id, request.FileExtension);
    var result = await sender.Send(command, cancellationToken);
    return TypedResults.Ok(result);
})
.WithName("CreateCourseThumbnailUploadUrl")
.WithSummary("Sinh presigned URL để client upload ảnh thumbnail thẳng lên MinIO");
 
group.MapPut("/{id:guid}/thumbnail", async (
    Guid id,
    UpdateCourseThumbnailRequest request,
    ISender sender,
    CancellationToken cancellationToken) =>
{
    await sender.Send(new UpdateCourseThumbnailCommand(id, request.ObjectKey), cancellationToken);
    return TypedResults.NoContent();
})
.WithName("UpdateCourseThumbnail")
.WithSummary("Xác nhận thumbnail sau khi upload MinIO thành công");

## **Bài tập thực hành**

> **✏️ Thực hành:** Thêm chức năng xóa thumbnail — DELETE /api/v1/courses/{id}/thumbnail.
>
> Input: CourseId của course đang có ThumbnailObjectKey khác null.
>
> Expected output: gọi xong, ThumbnailObjectKey trong DB trả về null, và object thật trên MinIO bị xóa (kiểm tra lại bằng MinIO Console).
>
> Hint 1: Domain cần thêm method Course.ClearThumbnail() — set ThumbnailObjectKey = null, tuân theo đúng nguyên tắc aggregate boundary đã học ở phần 2.
>
> Hint 2: IFileStorageService cần thêm method DeleteAsync(string objectKey, CancellationToken ct) — implement bằng RemoveObjectAsync(new RemoveObjectArgs().WithBucket(...).WithObject(objectKey)) của MinIO SDK.
>
> Hint 3: DeleteCourseThumbnailCommandHandler phải đọc ThumbnailObjectKey hiện tại của Course TRƯỚC khi gọi ClearThumbnail() — nếu clear trước, mất luôn objectKey cần xóa trên MinIO.

## **Tổng kết**

> **✅ Recap bài 1.8**
>
> 1. Upload ảnh dùng presigned URL, không proxy file qua backend — backend chỉ ký URL, không chạm byte ảnh nào.
>
> 2. Luồng thật sự là 3 bước, cần 2 Command: CreateCourseThumbnailUploadUrlCommand (sinh URL) và UpdateCourseThumbnailCommand (xác nhận, ghi vào Aggregate).
>
> 3. Course Aggregate chỉ lưu ObjectKey, không lưu full URL — tách biệt dữ liệu nghiệp vụ khỏi hạ tầng lưu trữ.
>
> 4. MinIO đăng ký qua AddMinio().WithStaticCredentials(...) — builder API mới của MinIO .NET SDK, hỗ trợ chính thức .NET 10.
>
> 5. Mọi thay đổi trên Course vẫn đi qua đúng 1 điểm vào duy nhất: chính Aggregate Root (SetThumbnail) — không có ngoại lệ cho binary data.

ObjectKey của thumbnail sẽ quay lại ở bài 1.7-nối-tiếp khi GetCourseDetailQuery cần trả thêm field ThumbnailUrl (ghép base URL MinIO + ObjectKey ở tầng Query), và ở bài 6.5 khi React Admin implement lại đúng luồng 3 bước này từ phía UI.

## **Phụ lục — Quick Reference**

| **Thành phần** | **Mô tả** |
|---|---|
| POST /api/v1/courses/{id}/thumbnail/upload-url | Sinh presigned PUT URL, trả về objectKey + uploadUrl + expiresAt |
| PUT \<uploadUrl> | Client PUT trực tiếp file ảnh lên MinIO — không qua TEDU Market API |
| PUT /api/v1/courses/{id}/thumbnail | Xác nhận, ghi objectKey vào Course Aggregate qua SetThumbnail |
| IFileStorageService | Interface ở Application — Application không biết gì về MinIO |
| MinioFileStorageService | Implementation ở Infrastructure, dùng IMinioClient (MinIO .NET SDK) |
| http://localhost:9001 | MinIO Console — xem bucket/object trực quan lúc debug |
