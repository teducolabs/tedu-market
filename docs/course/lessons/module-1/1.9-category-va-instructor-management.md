## **Nội dung chính**

### **1. Ôn lại pattern — vì sao bài này không có kỹ thuật mới (5 phút)**

Từ bài 0.4 đến 1.8, bạn đã lặp lại đúng 1 khuôn hình 8 lần: Command/Query → Validator → Handler → Repository (EF Core cho write, Dapper cho read) → Endpoint → map lỗi qua ProblemDetails. Bài 1.9 không dạy khái niệm mới — nó là bài kiểm tra xem pattern đã thành phản xạ chưa. Có 2 việc cần làm:

- Category: đã có Create (0.4) và đọc danh sách (0.8) — còn thiếu Update và Delete để gọi là 'CRUD hoàn chỉnh'.
- Instructor: hoàn toàn chưa có Aggregate — bạn tự dựng từ đầu, dùng đúng khuôn Category đã học.

> **📘 Ghi chú giảng viên:** *Tôi luôn mở đầu bài này bằng câu hỏi: 'Ai nhớ chính xác 6 bước từ Command đến Response không cần mở lại bài cũ?' Học viên nào ấp úng ở bước nào, đó là chỗ cần ôn lại trước khi vào Lab, tránh việc các bạn bị kẹt Instructor ở giữa chừng vì hổng kiến thức nền chứ không phải vì bài khó.*

### **2. Demo: Hoàn thiện CRUD Category — Update & Delete (10 phút)**

Category entity đã có từ bài 0.3 với invariant "tên không được rỗng". Thêm method Rename() tái sử dụng đúng logic validate đó thay vì viết lại:

*backend/src/TeduMarket.Domain/Catalog/Category.cs — bổ sung vào class đã có*

```csharp
public sealed class Category
{
    public Guid Id { get; private set; }
    public string Name { get; private set; } = default!;
 
    private Category() { } // EF Core
 
    public Category(string name)
    {
        Id = Guid.NewGuid();
        SetName(name);
    }
 
    // Mới ở bài 1.9 — tái sử dụng SetName() đã có từ bài 0.3,
    // không viết lại logic validate tên rỗng.
    public void Rename(string name) => SetName(name);
 
    private void SetName(string name)
    {
        if (string.IsNullOrWhiteSpace(name))
            throw new ArgumentException("Tên Category không được để trống.", nameof(name));
 
        Name = name.Trim();
    }
}
```

UpdateCategoryCommand — đúng khuôn CreateCategoryCommand ở bài 0.4, chỉ đổi động từ:

*backend/src/TeduMarket.Application/Catalog/Categories/UpdateCategory/UpdateCategoryCommand.cs*

```csharp
public sealed record UpdateCategoryCommand(Guid Id, string Name) : IRequest;
 
public sealed class UpdateCategoryCommandValidator : AbstractValidator<UpdateCategoryCommand>
{
    public UpdateCategoryCommandValidator()
    {
        RuleFor(x => x.Id).NotEmpty();
        RuleFor(x => x.Name).NotEmpty().MaximumLength(200);
    }
}
 
public sealed class UpdateCategoryCommandHandler(ICategoryRepository repository)
    : IRequestHandler<UpdateCategoryCommand>
{
    public async Task Handle(UpdateCategoryCommand request, CancellationToken cancellationToken)
    {
        var category = await repository.GetByIdAsync(request.Id, cancellationToken)
            ?? throw new CategoryNotFoundException(request.Id); // đã có từ bài 0.9
 
        category.Rename(request.Name);
 
        await repository.UpdateAsync(category, cancellationToken);
    }
}
```

Delete là chỗ có điểm mới thật sự trong toàn bài: một business rule chưa từng xuất hiện — không được xóa Category còn Course tham chiếu. Đây là lúc phân biệt exception "not found" (404) với exception "vi phạm rule nghiệp vụ" (409):

*backend/src/TeduMarket.Application/Catalog/Categories/DeleteCategory/DeleteCategoryCommand.cs*

```csharp
public sealed record DeleteCategoryCommand(Guid Id) : IRequest;
 
public sealed class DeleteCategoryCommandHandler(
    ICategoryRepository categoryRepository,
    ICourseRepository courseRepository)
    : IRequestHandler<DeleteCategoryCommand>
{
    public async Task Handle(DeleteCategoryCommand request, CancellationToken cancellationToken)
    {
        var category = await categoryRepository.GetByIdAsync(request.Id, cancellationToken)
            ?? throw new CategoryNotFoundException(request.Id);
 
        // Business rule mới: Category còn Course thì không được xóa.
        var hasCourses = await courseRepository.ExistsByCategoryIdAsync(request.Id, cancellationToken);
        if (hasCourses)
            throw new CategoryInUseException(request.Id);
 
        await categoryRepository.DeleteAsync(category, cancellationToken);
    }
}
```

CategoryInUseException đặt tên đúng convention {Thực thể}{LoạiLỗi}Exception ở mục 7. ExistsByCategoryIdAsync là method mới cần bổ sung vào ICourseRepository (interface đã có từ Module 1) — đây là 1 dòng, không phải thiết kế lại repository.

> **📘 Ghi chú giảng viên:** *Lỗi phổ biến nhất tôi thấy học viên mắc ở Delete: gọi thẳng categoryRepository.DeleteAsync() rồi để Postgres tự chặn bằng foreign key constraint, sau đó bắt exception SQL chung chung ở middleware. Cách đó vẫn ra lỗi 500 khó hiểu cho client. Phải nhấn mạnh: business rule nằm trong Application layer, không đẩy trách nhiệm xuống database — đây chính là lý do CQRS + Clean Architecture cho phép trả lỗi 409 rõ ràng thay vì exception SQL bò lên tận HTTP response.*

Map exception mới vào Exception Handling Middleware đã xây ở bài 0.9 — bổ sung 1 nhánh, không viết lại middleware:

*backend/src/TeduMarket.Api/Middleware/ExceptionHandlingMiddleware.cs — bổ sung switch case*

```

```

### **3. Lab: Tự xây Instructor CRUD hoàn chỉnh (15 phút)**

Instructor là Aggregate hoàn toàn mới, thuộc bounded context Catalog cùng với Category. Course.InstructorId đã tồn tại từ bài 1.2 nhưng đến giờ vẫn chỉ là một Guid trôi nổi — Instructor Aggregate ở bài này chính là thứ đứng đằng sau Guid đó.

> **✏️ Thực hành:** Tự cài đặt đầy đủ CRUD cho Instructor, đúng khuôn Category vừa làm ở phần Demo, không copy-paste — gõ lại để pattern thấm. Không cần hỏi lại giảng viên bất kỳ chi tiết nào có trong checklist dưới đây.

Checklist bắt buộc (đúng naming convention mục 7 của outline):

- Domain: TeduMarket.Domain/Catalog/Instructor.cs — Aggregate với Id, Name, Headline (chức danh ngắn), Bio, AvatarUrl. Invariant: Name không được rỗng (copy logic SetName từ Category, không phát minh lại).
- Domain: InstructorNotFoundException, InstructorInUseException — kế thừa đúng base exception đã dùng cho CategoryNotFoundException ở bài 0.9.
- Application: CreateInstructorCommand (trả về Guid, giống CreateCategoryCommand bài 0.4), UpdateInstructorCommand, DeleteInstructorCommand — mỗi Command có Validator riêng.
- Application: GetInstructorDetailQuery (Get{Entity}DetailQuery, giống GetCourseDetailQuery bài 1.7) và GetInstructorsListQuery (Get{Entity}ListQuery, giống GetCoursesListQuery bài 1.6) — cả hai dùng Dapper, không dùng EF Core cho Query side.
- Application: bổ sung 1 method ExistsByInstructorIdAsync vào ICourseRepository đã có, dùng cho DeleteInstructorCommandHandler chặn xóa Instructor còn Course.
- Infrastructure: IInstructorRepository + InstructorRepository (EF Core), InstructorConfiguration : IEntityTypeConfiguration\<Instructor> (Owned/Fluent API tối thiểu — không có Owned Type vì Instructor không có Value Object con).
- Infrastructure: migration mới \`dotnet ef migrations add AddInstructor\` chạy qua IDesignTimeDbContextFactory đã cấu hình ở bài 1.5.
- Api: MapGroup("/api/v1/instructors") với đủ POST / GET / GET {id} / PUT {id} / DELETE {id}, response 201/200/204/404/409 nhất quán với Category.

Input/Expected output để tự kiểm tra:

- POST /api/v1/instructors với { "name": "Bạch Ngọc Toàn", "headline": "Senior .NET Instructor" } → 201 Created, body { id }.
- GET /api/v1/instructors → 200, danh sách chứa Instructor vừa tạo.
- DELETE /api/v1/instructors/{id} khi Instructor đã được gán cho 1 Course (qua Course.InstructorId ở bài 1.2) → 409 Conflict, không phải 500.

```csharp
namespace TeduMarket.Domain.Catalog;
 
public sealed class Instructor
{
    public Guid Id { get; private set; }
    public string Name { get; private set; } = default!;
    public string? Headline { get; private set; }
    public string? Bio { get; private set; }
    public string? AvatarUrl { get; private set; }
 
    private Instructor() { } // EF Core
 
    public Instructor(string name, string? headline, string? bio)
    {
        Id = Guid.NewGuid();
        SetName(name);
        Headline = headline;
        Bio = bio;
    }
 
    public void UpdateProfile(string name, string? headline, string? bio)
    {
        SetName(name);
        Headline = headline;
        Bio = bio;
    }
 
    // Dùng lại luồng presigned URL MinIO từ bài 1.8
    public void SetAvatar(string avatarUrl) => AvatarUrl = avatarUrl;
 
    private void SetName(string name)
    {
        if (string.IsNullOrWhiteSpace(name))
            throw new ArgumentException("Tên Instructor không được để trống.", nameof(name));
 
        Name = name.Trim();
    }
}
```

### **Application — Commands**

```csharp
public sealed record CreateInstructorCommand(string Name, string? Headline, string? Bio) : IRequest<Guid>;
 
public sealed class CreateInstructorCommandValidator : AbstractValidator<CreateInstructorCommand>
{
    public CreateInstructorCommandValidator()
    {
        RuleFor(x => x.Name).NotEmpty().MaximumLength(200);
        RuleFor(x => x.Headline).MaximumLength(150);
        RuleFor(x => x.Bio).MaximumLength(2000);
    }
}
 
public sealed class CreateInstructorCommandHandler(IInstructorRepository repository)
    : IRequestHandler<CreateInstructorCommand, Guid>
{
    public async Task<Guid> Handle(CreateInstructorCommand request, CancellationToken cancellationToken)
    {
        var instructor = new Instructor(request.Name, request.Headline, request.Bio);
        await repository.AddAsync(instructor, cancellationToken);
        return instructor.Id;
    }
}
 
public sealed record UpdateInstructorCommand(Guid Id, string Name, string? Headline, string? Bio) : IRequest;
 
public sealed class UpdateInstructorCommandHandler(IInstructorRepository repository)
    : IRequestHandler<UpdateInstructorCommand>
{
    public async Task Handle(UpdateInstructorCommand request, CancellationToken cancellationToken)
    {
        var instructor = await repository.GetByIdAsync(request.Id, cancellationToken)
            ?? throw new InstructorNotFoundException(request.Id);
 
        instructor.UpdateProfile(request.Name, request.Headline, request.Bio);
        await repository.UpdateAsync(instructor, cancellationToken);
    }
}
 
public sealed record DeleteInstructorCommand(Guid Id) : IRequest;
 
public sealed class DeleteInstructorCommandHandler(
    IInstructorRepository instructorRepository,
    ICourseRepository courseRepository)
    : IRequestHandler<DeleteInstructorCommand>
{
    public async Task Handle(DeleteInstructorCommand request, CancellationToken cancellationToken)
    {
        var instructor = await instructorRepository.GetByIdAsync(request.Id, cancellationToken)
            ?? throw new InstructorNotFoundException(request.Id);
 
        var hasCourses = await courseRepository.ExistsByInstructorIdAsync(request.Id, cancellationToken);
        if (hasCourses)
            throw new InstructorInUseException(request.Id);
 
        await instructorRepository.DeleteAsync(instructor, cancellationToken);
    }
}
```

### **Application — Queries (Dapper)**

```csharp
public sealed record InstructorListItemDto(Guid Id, string Name, string? Headline, string? AvatarUrl);
 
public sealed record GetInstructorsListQuery : IRequest<IReadOnlyList<InstructorListItemDto>>;
 
public sealed class GetInstructorsListQueryHandler(NpgsqlDataSource dataSource)
    : IRequestHandler<GetInstructorsListQuery, IReadOnlyList<InstructorListItemDto>>
{
    public async Task<IReadOnlyList<InstructorListItemDto>> Handle(
        GetInstructorsListQuery request, CancellationToken cancellationToken)
    {
        const string sql = """
            SELECT "Id", "Name", "Headline", "AvatarUrl"
            FROM "Instructors"
            ORDER BY "Name"
            """;
 
        await using var connection = dataSource.CreateConnection();
        var result = await connection.QueryAsync<InstructorListItemDto>(
            new CommandDefinition(sql, cancellationToken: cancellationToken));
 
        return result.ToList();
    }
}
 
public sealed record InstructorDetailDto(Guid Id, string Name, string? Headline, string? Bio, string? AvatarUrl);
 
public sealed record GetInstructorDetailQuery(Guid Id) : IRequest<InstructorDetailDto?>;
 
public sealed class GetInstructorDetailQueryHandler(NpgsqlDataSource dataSource)
    : IRequestHandler<GetInstructorDetailQuery, InstructorDetailDto?>
{
    public async Task<InstructorDetailDto?> Handle(
        GetInstructorDetailQuery request, CancellationToken cancellationToken)
    {
        const string sql = """
            SELECT "Id", "Name", "Headline", "Bio", "AvatarUrl"
            FROM "Instructors"
            WHERE "Id" = @Id
            """;
 
        await using var connection = dataSource.CreateConnection();
        return await connection.QuerySingleOrDefaultAsync<InstructorDetailDto>(
            new CommandDefinition(sql, new { request.Id }, cancellationToken: cancellationToken));
    }
}
```

```csharp
public interface IInstructorRepository
{
    Task<Instructor?> GetByIdAsync(Guid id, CancellationToken cancellationToken);
    Task AddAsync(Instructor instructor, CancellationToken cancellationToken);
    Task UpdateAsync(Instructor instructor, CancellationToken cancellationToken);
    Task DeleteAsync(Instructor instructor, CancellationToken cancellationToken);
}
 
public sealed class InstructorConfiguration : IEntityTypeConfiguration<Instructor>
{
    public void Configure(EntityTypeBuilder<Instructor> builder)
    {
        builder.ToTable("Instructors");
        builder.HasKey(x => x.Id);
 
        builder.Property(x => x.Name).HasMaxLength(200).IsRequired();
        builder.Property(x => x.Headline).HasMaxLength(150);
        builder.Property(x => x.Bio).HasMaxLength(2000);
        builder.Property(x => x.AvatarUrl).HasMaxLength(500);
    }
}
```

### **Cheat sheet naming convention — nhắc lại mục 7 outline**

- Command: {Động từ}{Thực thể}Command — CreateInstructorCommand, UpdateInstructorCommand, DeleteInstructorCommand.
- Handler: {Tên Command}Handler — CreateInstructorCommandHandler.
- Query: Get{Thực thể}DetailQuery (1 item) / Get{Thực thể}ListQuery (danh sách) — GetInstructorDetailQuery, GetInstructorsListQuery.
- Exception: {Thực thể}{LoạiLỗi}Exception — InstructorNotFoundException (404), InstructorInUseException (409).
- Endpoint route: /api/v1/{số nhiều thực thể} — /api/v1/instructors.
